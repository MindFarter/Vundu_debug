Tools

      

      
Everything installs inside this folder under data/engines/debug/. Tools already installed by ESP-IDF in ~/.espressif are found and used automatically.

      

    
Linux: USB permission rule

      
OpenOCD talks to the JTAG function with libusb, which needs access to the raw USB device. Run this once, then unplug and replug the board.

      

      

    
Vundu_lab and Vundu_debug

      
The two tools are separate programs that take turns with the board. The Vundu_lab button (top right) stops the debug session, lets go of the board and opens Vundu_lab. Opening this page again resumes the debugger.
